Import from a device export

Pick a Garmin GPX or a Lowrance .usr (format 6) file exported from your sounder's own "export waypoints" option. Every waypoint is matched against what's already in the marks database before anything is saved — spots the device saved more than once (a common thing chartplotters do when you drift back over the same mark) are merged into one, and anything within 20m of a mark already tracked is left out of the list entirely, so nothing gets imported twice. Review and edit below, then import only what you actually want kept.

Export to a device

Downloads every mark currently in the marks database as a GPX file — Lowrance and Garmin each want a slightly different <sym> icon format, so export the one for whichever device you're loading onto (see the Mark Formats in Fishing Mark Lists, on the Settings tab, to control exactly what each device shows).
