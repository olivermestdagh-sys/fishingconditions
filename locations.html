GitHub connection

Locations, Location Groups, and Fishing Mark Lists no longer use this — they save straight to your account once you're signed in as Admin (see the Account tab). This connection is only for two things now: setting a Home address (still stored in the repo's config/settings.json) and the "Refresh data now" button (triggers a GitHub Actions run immediately). Fishing Mark Lists

The pick-from options used when logging a fishing mark (a catch or a point of interest) out on the water — species, bait, weather/tide/water conditions, gear. Saved immediately to your account as you add, remove, or edit them — no separate Save step any more.

Sign in with Google as Admin on the Account tab to manage mark lists.
